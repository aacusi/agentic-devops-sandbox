# .claude/commands/

Project slash commands. Empty until there is a workflow worth repeating verbatim.

A command earns its place here when you have typed the same multi-step sequence
three times: the value is that the steps are identical every session, rather than
improvised from context. See the planned list in `../README.md`.

Format: one Markdown file per command, filename = command name
(`cluster-status.md` -> `/cluster-status`), with optional YAML frontmatter for
`description` and `allowed-tools`.
